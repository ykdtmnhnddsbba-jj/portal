手帖ポータル

ゲーム（記録・攻略）、アニメ、映画・ドラマ、謎解き、読書（図書館・本の売買）、旅行、家族、やりたいことのサイトへの入口です。

今日のまとめ

    この端末で開いたことのある手帖の記録から作っています（ログイン不要。どこにも送りません）。

    記録の手帖

    ゲーム手帖

    ゲームを発売月ごとに整理し、評価や好みの分析、おすすめ作品を見られます。

    ゲーム手帖を開く GitHub

    攻略手帖

    ゲームごとのトロフィー一覧と攻略チャートです。PSNの取得状況が自動で反映され、残りのトロフィーだけを順番に追えます。

    攻略手帖を開く GitHub

    アニメ手帖

    アニメの評価や好みの分析、クール別のおすすめを見られます。

    アニメ手帖を開く GitHub

    映画ドラマ手帖

    観たい映画をメモして、観たら評価と一言メモを残せます。日本のドラマはクール別に一覧で、Prime Video・Netflixの配信も確認できます。

    映画ドラマ手帖を開く GitHub

    謎解き手帖

    謎解き公演の感想、成績、教訓を記録します。

    謎解き手帖を開く GitHub

    図書館手帖

    ブクログの「読みたい・積読」の本が、池田町・神戸町の図書館にあるか（貸出可か）を、書影つきで確認できます。

    図書館手帖を開く GitHub

    本の手帖

    会社の書籍補助で買うIT・ビジネス書を、メルカリで売ったときの実質負担が小さい順に選べます。買った本を月ごとに記録し、補助の残り枠も確認できます。

    本の手帖を開く GitHub

    脳トレ日記

    毎日の日記を音声入力で書けます。ごはんの思い出しクイズ、3つの良いこと、運動の記録つき。カレンダーと検索で見返せます（自分用）。

    脳トレ日記を開く

    自分

    やりたいこと手帖

    やりたいことを短期・中期・長期・毎日の習慣に分けて管理します。スマホからすぐメモでき、習慣は毎日チェックして連続日数を確認できます。Claudeプロジェクトの指示文もコピーできます。

    やりたいこと手帖を開く GitHub

    旅行

    旅のしおり

    家族旅行の行程表です。日別のタイムライン、チケット、Googleマップの経路、持ち物チェックを見られます。

    旅のしおりを開く GitHub

    しおり編集室

    しおりの作成・修正・削除をします。カレンダーから骨子を作れます。公開サイトへの反映もここから依頼します（自分用・Claudeへのログインが必要）。

    しおり編集室を開く

    家族

    HOME✦MISSION

    家族のルーティーンとToDoを管理して、担当者のスマホに通知します。完了するまで再通知し、家族の完了状況も一覧で見られます。

    HOME✦MISSIONを開く GitHub

    ハムスター手帖

    部屋の掃除と大掃除の前回日・次回日を管理します。周期から次回日を自動計算し、手でも直せます。Googleカレンダーへの登録もできます。

    ハムスター手帖を開く GitHub

    車、ちょっと借ります

    車を借りる時間（開始・返す時刻）を予約して共有します。メモや繰り返し設定、LINE通知にも対応しています。

    車、ちょっと借ります を開く
