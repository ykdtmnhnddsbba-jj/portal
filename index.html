手帖ポータル

ゲーム、アニメ、映画・ドラマ、謎解き、読書（図書館）、旅行、家族のサイトへの入口です。

記録の手帖

ゲーム手帖

ゲームを発売月ごとに整理し、評価や好みの分析、おすすめ作品を見られます。

ゲーム手帖を開く GitHub

アニメ手帖

アニメの評価や好みの分析、クール別のおすすめを見られます。

アニメ手帖を開く GitHub

映画ドラマ手帖

観たい映画をメモして、観たら評価と一言メモを残せます。日本のドラマはクール別に一覧で、Prime Video・Netflixの配信も確認できます。

映画ドラマ手帖を開く GitHub

謎解き手帖

謎解き公演の感想、成績、教訓を記録します。

謎解き手帖を開く GitHub

図書館手帖

ブクログの「読みたい・積読」の本が、池田町・神戸町の図書館にあるか（貸出可か）を、書影つきで確認できます。

図書館手帖を開く GitHub

旅行

旅のしおり

家族旅行の行程表です。日別のタイムライン、チケット、Googleマップの経路、持ち物チェックを見られます。

旅のしおりを開く GitHub

しおり編集室

しおりの作成・修正・削除をします。カレンダーから骨子を作れます。公開サイトへの反映もここから依頼します（自分用・Claudeへのログインが必要）。

しおり編集室を開く

家族

HOME✦MISSION

家族のルーティーンとToDoを管理して、担当者のスマホに通知します。完了するまで再通知し、家族の完了状況も一覧で見られます。

HOME✦MISSIONを開く GitHub

車、ちょっと借ります

車を借りる時間（開始・返す時刻）を予約して共有します。メモや繰り返し設定、LINE通知にも対応しています。

車、ちょっと借ります を開く
スマホではこのページをホーム画面に追加すると、1タップで各サイトへ移動できます。
